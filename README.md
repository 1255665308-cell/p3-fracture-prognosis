# P3 fracture prognosis

Public browser-based research calculator for 730-day mortality after fracture discharge. Two-factor primary model and 16-factor comparator; English and Chinese. No prediction inputs are uploaded or persistently stored. Research use; no independent-hospital clinical validation is claimed.

All paths are relative and support a GitHub Pages project subdirectory. Publish the main branch, root folder, in repository Settings → Pages. `.nojekyll` preserves the static module assets. No build, server, API key or database is required.

The downloaded publication parameter hash is b85c50554cfabab67edbb1625c6d3efdd8e2aa0a2d5f812cba226930ec7a427a. This is the same model implementation as the verified public research release P3-Web-20261031-v2.1.
